Using remote memory for efficient resource utilization is rapidly gaining
attention with the rising popularity of high-performance networks. This project
proposed a tailored remote memory system for virtualized environments, reducing
remote paging latency by 41.7x at the tail and improving job execution time by
3.5x under intensive remote paging scenarios.

Published at PACT'20.
